CompactLES.CompactLES — Module
CompactLES

Compressible large-eddy/direct-simulation solver using high-order compact finite differences, compact filtering, five-stage fourth-order low-storage Runge–Kutta time integration, shared-memory threading, and MPI domain decomposition. The compact line solves remain globally coupled across decomposed dimensions.

The public frontend separates a pointwise Problem from its Numerics; setup returns the distributed solver and the initialized conserved state.
