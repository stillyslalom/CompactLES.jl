# Verification, validation, and calibration

These activities answer different questions.

- **Code verification:** does the implementation solve the discrete equations
  that were intended?
- **Solution verification:** how large is the discretization error in this
  calculation?
- **Validation:** does the mathematical model reproduce an independent
  physical or analytic reference for the intended use?
- **Calibration:** which model or regularization parameters best fit specified
  reference data?

A test can contribute to more than one activity, but the terms should not be
used interchangeably.

## Serial code verification

```sh
julia --project=. test/runtests.jl
```

The serial suite checks banded algebra, compact derivatives, closure
polynomials, filters, curvilinear folds, freestream preservation, conservation,
EOS round trips, boundary conditions, callbacks, diagnostics, and I/O. Exact or
manufactured identities isolate implementation errors without requiring a long
hydrodynamic run.

## Observed-order studies

```sh
julia --project=. test/convergence.jl
```

The suite fits error over several resolutions. Current regression values are
approximately:

| Configuration | Observed maximum-norm order |
|:--|--:|
| periodic C6 | 6.01 |
| periodic C10 | 10.04 |
| closed C6 wall closure | 3.17 |
| cylindrical-axis odd/even folds | 3.71 / 3.00 |
| resolved-angle cylindrical fold | 3.71 |
| spherical origin | 2.99 |

For a change not intended to alter numerics, compare the error magnitudes as
well as fitted slopes. A changed magnitude with an unchanged order can still
identify a real change to the discrete operator.

## Distributed equivalence

```sh
mpiexec -n 2 julia --project=. -t 1 test/mpi_tests.jl
mpiexec -n 4 julia --project=. -t 1 test/mpi_tests.jl
mpiexec -n 8 julia --project=. -t 1 test/mpi_tests.jl
```

These tests change block ownership and interface patterns while comparing with
serial behavior. They cover distributed tridiagonal and pentadiagonal solves,
halo exchange, off-rank coordinate folds, discrete GCL construction, and
telescoping conservation.

## Shock validation battery

```sh
julia --project=. test/validation.jl
```

Lax, Sedov--Taylor, and Noh cases are compared with closed-form references.
Shu--Osher and Woodward--Colella are compared with stored high-resolution
profiles generated by this code; those are regression references rather than
independent absolute validation. Noh is exercised in multiple geometries to
probe axis and origin treatments under a strong shock.

Nonlinear shock cases are not bit-reproducible under every harmless arithmetic
reassociation. Compare their reported errors to roughly four significant
figures; movement in an earlier digit warrants investigation.

## Artificial-property calibration

[`reference/CALIBRATION.md`](https://github.com/stillyslalom/CompactLES.jl/blob/main/reference/CALIBRATION.md)
records sweeps over Cook coefficients, CFL, and
Taylor--Green dissipation. Every reported coefficient is conditional on filter
strength, filter cadence, grid, EOS, and the reference cases used to select it.
Changing any of those invalidates a claim of unchanged calibration.

Current evidence includes two important limits:

- a converging strong shock is CFL-limited at the symmetry cell, at 0.4 for the
  spherical origin and 0.2 for the cylindrical axis and the planar wall under
  the default `smoother = :gaussian`; and
- the spherical origin requires initial data smooth over at least several
  cells.

## Verifying a new scientific calculation

For a production configuration:

1. state the quantity of interest and required accuracy;
2. repeat at multiple grids and, when relevant, timesteps;
3. check conservation and the location of timestep limits;
4. inspect artificial-property and filter sensitivity;
5. compare boundaries with a larger domain or independent treatment; and
6. compare with an analytic, experimental, or independently implemented
   reference appropriate to the same physical model.

Agreement with a package regression test establishes software continuity. It
does not by itself validate a new physical regime.
